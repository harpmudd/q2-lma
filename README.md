# q2-lma

An Internet Archive Live Music Archive (etree collection) browser and streamer for the Shanling Q2,
running as a [Q2 Pod](https://github.com/DiamondBond/q2-pod) card app.

Status: recon done, design next. See [docs/RECON.md](docs/RECON.md).

- Go, standard library only, static `mipsle` soft-float, no cgo.
- App id `lma` (the repo name less `q2-`): installs to `/mnt/mmc/.lma/`.
